# TrustLens

TrustLens is an AI-powered product transparency analyzer that helps users understand the ingredients and claims of food and cosmetic products.

## Features

- **Ingredient Analysis:** Extracts ingredients from product labels using OCR.
- **Trust Score:** Generates a report to help users understand potential product risks.
- **Allergen Detection:** Identifies potential allergens in product ingredients.
- **Claim Verification:** Helps evaluate product claims.
- **Safety Insights:** Provides general safety information for different users.
- **Report History:** Keeps track of previous analyses.

## Tech Stack

- **Frontend:** Next.js, React, TypeScript, Tailwind CSS
- **Backend:** Python, FastAPI
- **AI/ML:** OCR and Natural Language Processing
- **Database:** MySQL

## How It Works

1. Upload an image of a food or cosmetic product label.
2. The system extracts text and identifies ingredients.
3. AI analyzes the extracted information.
4. TrustLens generates a report with a trust score, ingredient insights, and potential risks.

## Project Purpose

TrustLens aims to make product information easier to understand and help users make more informed purchasing decisions.
